Open **Competitor Tracking** and click **Add channel**. You can add a channel two ways.

## Paste URL

Paste the channel's link into **Channel URL**. These formats work:

- `youtube.com/@handle`, including links to a tab like `youtube.com/@handle/videos`
- `youtube.com/channel/UC…`
- Just the handle: `@handle`
- Just the channel ID, the one starting with `UC`

Links with or without `https://`, `www.` or `m.` all work.

Older links like `youtube.com/c/name` or `youtube.com/user/name` don't work. Open the channel on YouTube and copy its `@handle` link instead.

Adding a channel by link is free.

## Search

Type the channel's name to search for it. This runs a channel search, so it costs <Fact k="credits.nicheSearch" unit="credit" />, the same as a Niche Finder search.

## Limits

Each plan can track a set number of channels. See [Saving channels to tracking](/help/saving-channels) for the numbers.
