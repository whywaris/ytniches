Thumbnail ideas start from an outlier. On any outlier card, click **Get thumbnail ideas**, then **Generate thumbnail ideas**.

You get thumbnail concepts built around what made that video work.

## Cost

A set of ideas costs <Fact k="credits.thumbnailIdeas" unit="credit" />. Want different ones? **Generate another** runs a fresh set for <Fact k="credits.thumbnailIdeasRegenerate" unit="credit" />. There's no feedback step here, so each set is a full new run.
